The dates come from CCF Deadlines (ccfddl.com), a list kept up to date by the research community. This page reads each conference's file in its repository, conference/, each time it opens, so a new edition appears here as soon as it is added there. FAccT is not in that list; its dates come from Hugging Face's AI Deadlines (facct.yml). ITCS is in neither list yet.

If a date is missing or wrong, anyone can correct it with a pull request to github.com/ccfddl/ccf-deadlines or github.com/huggingface/ai-deadlines.

Deadlines are shown in the time zone the list gives (AoE is UTC−12), and also in your own time. Check the conference website before you submit.

The dates come from Security and Privacy Deadlines (sec-deadlines.github.io), a list kept up to date by the security and privacy community. This page reads its data file, _data/conferences.yml, each time it opens, so a new edition appears here as soon as it is added there.

If a date is missing or wrong, anyone can correct it with a pull request to github.com/sec-deadlines/sec-deadlines.github.io.

Deadlines are Anywhere on Earth (AoE, UTC−12) unless another time zone is shown, and also given in your own time. The list notes abstract registration in a comment (for example "1 week before deadline"); the abstract deadlines here are worked out from it. Check the conference website before you submit.
