Settings

Some services, arXiv among them, do not answer pages on other websites directly. The app then tries public CORS proxies, which can be slow or down. For a reliable route, put your own proxy here; {url} is replaced by the encoded address. A five-line Cloudflare Worker is enough:

export default { async fetch(req) {
  const url = new URL(req.url).searchParams.get('url');
  const r = await fetch(url, { headers: { 'User-Agent': 'literature-apps' } });
  const h = new Headers(r.headers); h.set('Access-Control-Allow-Origin', '*');
  return new Response(r.body, { status: r.status, headers: h });
} };
