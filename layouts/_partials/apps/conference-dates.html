Source

The dates come from Security and Privacy Deadlines (sec-deadlines.github.io), a list kept up to date by the security and privacy community. This page reads its data file, _data/conferences.yml, each time it opens, so a new edition appears here as soon as it is added there.

If a date is missing or wrong, anyone can correct it with a pull request to github.com/sec-deadlines/sec-deadlines.github.io.

Deadlines are Anywhere on Earth (AoE, UTC−12) unless another time zone is shown, and also given in your own time. Check the conference website before you submit.
